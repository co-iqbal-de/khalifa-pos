📱 Panduan Install KHALIFA POS

Ikuti langkah berikut agar app bisa dipakai seperti aplikasi HP biasa

1
Buka Netlify Drop di Browser
Netlify adalah layanan hosting gratis. Tidak perlu daftar untuk langsung upload.

Buka link ini di browser laptop atau HP:
🌐 Buka Netlify Drop
2
Siapkan Folder khalifa-pwa
Pastikan folder yang sudah didownload berisi file-file berikut:
📁 khalifa-pwa/
├── index.html
├── manifest.json
├── sw.js
└── 📁 icons/
    ├── icon-72.png
    ├── icon-96.png
    ├── icon-128.png
    ├── icon-144.png
    ├── icon-152.png
    ├── icon-192.png
    ├── icon-384.png
    └── icon-512.png
Penting: Upload seluruh FOLDER khalifa-pwa, bukan file satu per satu.
3
Drag & Drop Folder ke Netlify
Di halaman Netlify Drop, seret folder khalifa-pwa dan jatuhkan ke area bertuliskan "Drag and drop your site folder here".

Tunggu beberapa detik sampai proses upload selesai.

Netlify akan memberikan URL seperti:
https://wonderful-name-123.netlify.app
Simpan URL ini! Ini adalah link aplikasi KHALIFA POS milik kamu.
4
Buka URL di Chrome HP (Android)
1. Buka Chrome di HP Android
2. Ketik URL dari Netlify di address bar
3. Tunggu app terbuka sempurna
4. Akan muncul banner di bawah layar: "Install KHALIFA POS"
5. Tap tombol "Install"
6. App akan muncul di home screen seperti app biasa!

Atau bisa lewat menu Chrome:
⋮ → "Tambahkan ke layar utama"
5
Install di iPhone (Safari)
Khusus iPhone, gunakan Safari (bukan Chrome):
1. Buka URL di Safari
2. Tap ikon Share (kotak panah ke atas) di bawah layar
3. Scroll ke bawah, pilih "Add to Home Screen"
4. Tap "Add" di pojok kanan atas
5. App muncul di home screen dengan icon KHALIFA!
✅ Setelah Terinstall
App KHALIFA POS sudah siap dipakai!

• Buka dari home screen → tampil full screen seperti app asli
• Data tersimpan di HP, tidak hilang meski tutup app
• Bisa dipakai offline (setelah pertama kali dibuka online)
• Bagikan URL ke HP lain agar bisa dipakai bersama
• Tidak perlu Play Store atau App Store
